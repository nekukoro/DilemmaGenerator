# ジレンマみたいな
> **咎が正義か、<br>正義が咎か。<br>何気ない日常に、ありえない非日常を。**

## 前書き
条件がほんの少し変わっただけで、あなたの倫理観や決断は揺らぎますか？  
もし、思考実験の対象が人間ではなく「まったく別の存在」だったらどうでしょうか。

「ジレンマみたいな」は、有名なジレンマやパラドックスの数値を可変にし、予期せぬ状況をランダムに生み出すWebアプリケーションです。

何気ない日常の合間に、予想もしなかった選択肢と突き合わされることで、思考が少しだけ広がるような刺激的な体験を提供します。

## 概要
画面中央の「再抽選」ボタンを押すたびに、ジレンマの対象となる人物や条件となる数値などがランダムに組み替えられ、全く新しいシチュエーションが出力されます。

刻一刻と紡がれるテキストと、時折画面に走るノイズと共に、不気味で切迫感のある思考の世界へ没入していただけます。
